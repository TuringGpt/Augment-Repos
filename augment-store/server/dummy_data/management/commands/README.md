## Examples Usage

```bash
python manage.py generate_products
```

### Dry Run (Preview Only)
```bash
python manage.py generate_products --dry-run
```

### Delete Existing and Recreate
```bash
python manage.py generate_products --delete-existing
```

### Custom Static Path and Merchant
```bash
python manage.py generate_products --static-path /path/to/images --merchant-email dev@company.com
```
Merchant password is `testpass123`
